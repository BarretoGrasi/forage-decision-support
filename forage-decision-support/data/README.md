# Data

Place the curated dataset used by the manuscript in this directory as:

`forage_dataset.csv`

The manuscript reports 112 forage species/cultivars and 186 original fields:
3 identification fields and 183 descriptive attributes. A selected subset of
27 descriptors is used in the Gower-based multivariate representation.

The dataset itself is not included in this generated package because it was
not supplied together with the source-code file.
